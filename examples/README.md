## 怎么使用

1. 点示例名称查看预览、内容和历史限制。
2. 下载需要的一套 ZIP，解压后先看完整卡，再选单张视角；梁圣使用包内 HTML 查看卡片。
3. 使用 Release 的 `SHA256SUMS.txt` 校验 ZIP，包内 `manifest.json` 校验解压文件。

[机器可读目录](catalog.json) · [素材使用说明](USAGE.md)

## 历史与版本

本批保留用户指定目录中的现存历史版本，不擅自删图或从整卡裁切补造缺失原图。大肥鱼两套预览选已有 v002；Q版 v001 旧脸图未在所选目录中。梁圣是早期分区排版方法，不作为当前独立生成流程的合格示例。其他历史视图的构图也不代表当前 Skill 的默认全身要求。

后续新增或替换素材应使用新 Release 标签，保留旧包；同步更新各套 manifest、目录中的 URL 与 SHA-256，再验证公开下载。图片仅放 Releases，不提交到 Git 历史。
